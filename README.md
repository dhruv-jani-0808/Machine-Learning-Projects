## 🛠️ General Setup & Requirements

To explore and run the Jupyter notebooks in this repository:

1. **Install Dependencies:**
   Make sure you have Python installed, then install the necessary scientific libraries:
   ```bash
   pip install numpy pandas scikit-learn matplotlib seaborn openpyxl
   ```

2. **Datasets:**
   Since the datasets are large, they are not committed to GitHub. Please check the individual project folder's `README.md` for Kaggle links to download them.

3. **Run Notebooks:**
   Launch Jupyter Notebook or JupyterLab and open the `.ipynb` files in the respective project directories:
   ```bash
   jupyter notebook
   ```
